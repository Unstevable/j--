1. Provide a high-level description (ie, using minimal amount of technical
   jargon) of the project in no more than 200 words.

   This project tasked us with implementing the analysis and code generation of the same
   type of functionalities we have already implemented for the parser and the scanner for
   the j-- compiler.  Completion of this required understanding of the way the instruction
   code is generated by the compiler and thinking of the coding logic in a slightly different
   way than we might normally; like if we were to have -> while (a < b), instead of checking
   if a is less than b, we would make a jump to somewhere if a >= b, and so on.  I unfortunately
   didn't have enough time to complete this implementation of exception handlers and interfaces.
