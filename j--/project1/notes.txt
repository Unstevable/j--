1. Provide a high-level description (ie, using minimal amount of technical
   jargon) of the project in no more than 200 words.

This project mainly set a basis for our understanding of building the j-- Java sub-language.  In problem one, we programmatically generate the IsPrime class file; meaning, the base Java file for IsPrime does not exist, and we create it using code from another file labeled GenIsPrime.  We do this by utilizing the CLEmitter class and generating everything that would be present in the IsPrime class; from the beginning line of “public static void IsPrime” to the methods being called within.  Even though we are using the Java language as the basis for generating the IsPrime class, the logic behind it involves thinking in a manner akin to that as if we were coding in Assembly, so we have to keep track of what arguments and variables are on the stack we are using, as well as what is added to the stack with the proper order they are on it.  Problems two through four involve adding various operations to the j-- sub-language by editing the TokenInfo.java, Scanner.java, Parser.java, JBinaryExpression.java and JUnaryExpression.java files.  We added the following operations to the language: /, %, + (unary plus), ~, |, ^, &, <<, >> and >>>.
